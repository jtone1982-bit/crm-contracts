# Инструкция по работе с CRM "Контракты"

## 1. Общие сведения

**CRM "Контракты"** - система для работы с кандидатами в военный рекрутинг.

**Основной адрес:** https://tone-crm.ru  
**Резервный адрес (если основной не открывается):** https://ru.tone-crm.ru:8443

> **Важно:** С мобильного интернета CRM может не открываться из-за блокировки оператора. Используйте домашний Wi-Fi или VPN.

---

## 2. Инструкция для студента

### 2.1. Вход в систему

1. Откройте в браузере https://tone-crm.ru
2. Введите email и пароль, выданные руководителем.
3. Нажмите **Войти**.

Если нет аккаунта - обратитесь к руководителю.

### 2.2. Меню студента

Студенту доступны разделы:
- **Обучение** - прохождение курса и тестов
- **Профиль** - личные данные и настройки
- **Памятка** - эта инструкция

Раздел **Кандидаты** и другие менеджерские функции студенту недоступны.

### 2.3. Обучение

1. В меню выберите **Обучение**.
2. Откроется список модулей (разделов).
3. Каждый модуль состоит из:
   - Теории (текст, схемы, требования)
   - Теста на закрепление материала
   - Финального экзамена

### 2.4. Как проходить модуль

1. Нажмите на название модуля.
2. Прочитайте теорию.
3. Нажмите **Перейти к тесту**.
4. Ответьте на все вопросы.
5. Нажмите **Отправить ответы**.
6. Система покажет результат.

### 2.5. Тесты

- В каждом тесте есть вопросы с одним или несколькими вариантами ответа.
- На вопрос с несколькими вариантами можно выбрать несколько правильных ответов.
- Без ответа на все вопросы тест не отправляется.
- После отправки видно: сколько правильных ответов, сдан или нет.

### 2.6. Проходной балл

У каждого модуля указан проходной балл. Чтобы пройти модуль, нужно набрать не менее этого процента правильных ответов.

### 2.7. Финальный экзамен

- Финальный экзамен открывается только после прохождения всех обычных модулей.
- Если не все модули сданы - кнопка финального экзамена будет заблокирована.
- После сдачи финального экзамена обучение считается завершённым.

### 2.8. Повторные попытки

Если тест не сдан:
- Можно пересдать позже.
- Количество попыток ограничено.
- После пересдачи сохраняется лучший результат.

### 2.9. Профиль

В профиле можно посмотреть:
- ФИО и email
- Роль (студент)
- Результаты обучения
- Прогресс по модулям

### 2.10. Правила для студента

- Проходите обучение по порядку.
- Не передавайте логин и пароль другим.
- Если вопрос непонятен - перечитайте теорию или спросите руководителя.
- После завершения обучения дождитесь назначения роли менеджера.

## 3. Инструкция для менеджера

### 3.1. Вход и интерфейс

1. Зайдите на https://tone-crm.ru
2. Введите email и пароль.
3. В боковом меню доступны разделы:
   - **Кандидаты** - основная таблица
   - **Календарь** - план звонков и встреч
   - **Сообщения / Чат** - переписка
   - **Обучение** - тесты и материалы
   - **Отчёты** - только для админа
   - **Профиль** - настройки
   - **Инструменты** - дополнительные функции
   - **Памятка** - эта инструкция

### 3.2. Рабочий стол менеджера

В разделе **Кандидаты** показаны все ваши кандидаты.

Колонки таблицы:
- Телефон
- ФИО
- Город
- Статус
- Дата следующего контакта
- Комментарий
- Действия

### 3.3. Звонок кандидату

1. В таблице нажмите на номер телефона.
2. Откроется карточка с отдельной кнопкой звонка 📞.
3. Позвоните через обычный телефон или мессенджер.
4. После звонка обязательно:
   - Поменяйте статус
   - Запишите результат в комментарий
   - Установите дату следующего контакта

### 3.4. Смена статуса

1. Откройте карточку кандидата.
2. Нажмите на текущий статус.
3. Выберите новый статус из списка.
4. Сохраните.

### 3.5. Недозвон

Если не дозвонились:
1. Поставьте статус **Недозвон**.
2. Укажите причину:
   - Не берет трубку
   - Занят
   - Недоступен
   - Номер не существует
3. Установите дату и время следующей попытки.
4. Сохраните.

### 3.6. Заполнение анкеты

В карточке кандидата заполняйте все доступные поля:
- ФИО
- Дата рождения
- Город откуда / куда
- Группа здоровья
- Наличие документов
- Водительские права
- Семейное положение
- И другие

### 3.7. Загрузка документов

1. В карточке кандидата найдите раздел **Документы**.
2. Нажмите **Загрузить файл**.
3. Выберите файл с компьютера или телефона.
4. Подпишите документ: паспорт, СНИЛС, ИНН, военный билет и т.д.

### 3.8. Фильтры и поиск

В таблице кандидатов можно фильтровать:
- По статусу
- По городу
- По дате следующего контакта
- По менеджеру

Используйте фильтр **Сегодня**, чтобы видеть кандидатов, которым нужно позвонить сегодня.

### 3.9. Статусы кандидатов

| Статус | Что означает |
|--------|--------------|
| **На обзвон** | Новый кандидат, нужно позвонить |
| **Недозвон** | Не дозвонились, перезвонить позже |
| **В обработке** | Кандидат на этапе оформления |
| **Оформлен** | Документы собраны, кандидат оформлен |
| **Отказ** | Кандидат отказался |
| **Не актуален** | Неверный номер, дубль, окончательный отказ |

### 3.10. Мобильная работа

На iPhone/Safari:
- С мобильного интернета CRM может не открываться.
- Используйте домашний Wi-Fi.
- Или установите VPN.

Если CRM не грузится:
1. Попробуйте https://ru.tone-crm.ru:8443
2. Включите VPN
3. Переключитесь на Wi-Fi

### 3.11. Ежедневный порядок работы

1. Открыть **Кандидаты** - фильтр **На обзвон** и **Сегодня**.
2. Позвонить по списку.
3. Зафиксировать результат звонка.
4. Установить дату следующего контакта.
5. Перевести кандидатов в нужный статус.
6. Загрузить документы, если есть.
7. В конце дня проверить, нет ли пропущенных недозвонов.

### 3.12. Обучение для менеджера

Менеджеру также доступен раздел **Обучение**:
- Повторить материалы
- Пересдать тесты
- Проверить свои результаты

## 4. Частые проблемы

| Проблема | Решение |
|----------|---------|
| Не загружается сайт | Попробуйте резервный адрес ru.tone-crm.ru:8443, Wi-Fi или VPN |
| Забыл пароль | Обратитесь к руководителю |
| Не открывается тест | Проверьте интернет, перезагрузите страницу |
| Тест не отправляется | Убедитесь, что ответили на все вопросы |
| Нет доступа к кандидатам | Возможно, у вас роль студента. Дождитесь назначения менеджера |
| Не сохраняется карточка | Проверьте интернет, перезагрузите страницу |
| Не открывается документ | Проверьте формат и размер файла |
