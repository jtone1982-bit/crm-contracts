Инструкция по работе с CRM "Контракты"

1. Общие сведения

CRM "Контракты" - система для работы с кандидатами в военный рекрутинг.

Основной адрес: https://tone-crm.ru
Резервный адрес (если основной не открывается): https://ru.tone-crm.ru:8443

Важно: С мобильного интернета CRM может не открываться из-за блокировки оператора. Используйте домашний Wi-Fi или VPN.

2. Инструкция для новичка-студента

2.1. Вход в систему

  1. Откройте в браузере https://tone-crm.ru
  2. Введите email и пароль, выданные руководителем.
  3. Нажмите Войти.

Если нет аккаунта - обратитесь к руководителю.

2.2. Возможности студента

Студенту доступен режим помощника. Основные задачи:

  • Смотреть карточки кандидатов
  • Добавлять комментарии и заметки
  • Помогать заполнять анкеты
  • Проверять документы
  • Фиксировать результаты звонков

2.3. Работа с кандидатом

  1. В меню выберите раздел Кандидаты.
  2. Нажмите на строку с телефоном - откроется карточка.
  3. В карточке видно:
  4. ФИО, телефон, возраст
  5. Город прибытия и откуда приезжает
  6. Статус
  7. Комментарии
  8. Историю звонков
  9. Прикрепленные документы

2.4. Статусы кандидатов

Статус Что означает
На обзвон Новый кандидат, нужно позвонить
Недозвон Не удалось дозвониться, перезвонить позже
В обработке Кандидат на этапе оформления
Оформлен Документы собраны, кандидат оформлен
Отказ Кандидат отказался
Не актуален Неверный номер, дубль, окончательный отказ

Не меняйте статус без согласования с менеджером, если не уверены.

2.5. Как вести комментарии

  • В карточке кандидата есть поле Комментарий.
  • Пишите кратко и по делу: дату, суть разговора, договоренности.
  • Пример: 29.07 звонил, интересуется, приедет 05.08

2.6. Правила для новичка

  • Не удаляйте кандидатов.
  • Не меняйте статусы без разрешения.
  • Записывайте все в комментарии.
  • Если не уверены - спросите менеджера.

3. Инструкция для менеджера

3.1. Вход и интерфейс

  1. Зайдите на https://tone-crm.ru
  2. Введите email и пароль.
  3. В верхней панели:
  4. Кандидаты - основная таблица
  5. Сообщения / Чат - переписка
  6. Профиль - ваши настройки

3.2. Рабочий стол менеджера

В разделе Кандидаты показаны все ваши кандидаты.

Колонки таблицы: - Телефон - ФИО - Город - Статус - Дата следующего контакта - Комментарий - Действия

3.3. Звонок кандидату

  1. В таблице нажмите на номер телефона.
  2. Откроется карточка с отдельной кнопкой звонка.
  3. Позвоните через обычный телефон или мессенджер.
  4. После звонка обязательно:
  5. Поменяйте статус
  6. Запишите результат в комментарий
  7. Установите дату следующего контакта

3.4. Смена статуса

  1. Откройте карточку кандидата.
  2. Нажмите на текущий статус.
  3. Выберите новый статус из списка.
  4. Сохраните.

3.5. Недозвон

Если не дозвонились: 1. Поставьте статус Недозвон. 2. Укажите причину: - Не берет трубку - Занят - Недоступен - Номер не существует 3. Установите дату и время следующей попытки. 4. Сохраните.

3.6. Заполнение анкеты

В карточке кандидата заполняйте все доступные поля: - ФИО - Дата рождения - Город откуда / куда - Группа здоровья - Наличие документов - Водительские права - Семейное положение - И другие

3.7. Загрузка документов

  1. В карточке кандидата найдите раздел Документы.
  2. Нажмите Загрузить файл.
  3. Выберите файл с компьютера или телефона.
  4. Подпишите документ: паспорт, СНИЛС, ИНН, военный билет и т.д.

3.8. Фильтры и поиск

В таблице кандидатов можно фильтровать: - По статусу - По городу - По дате следующего контакта - По менеджеру

Используйте фильтр Сегодня, чтобы видеть кандидатов, которым нужно позвонить сегодня.

3.9. Мобильная работа

На iPhone/Safari: - С мобильного интернета CRM может не открываться. - Используйте домашний Wi-Fi. - Или установите VPN.

Если CRM не грузится: 1. Попробуйте https://ru.tone-crm.ru:8443 2. Включите VPN 3. Переключитесь на Wi-Fi

3.10. Ежедневный порядок работы

  1. Открыть Кандидаты - фильтр На обзвон и Сегодня.
  2. Позвонить по списку.
  3. Зафиксировать результат звонка.
  4. Установить дату следующего контакта.
  5. Перевести кандидатов в нужный статус.
  6. Загрузить документы, если есть.
  7. В конце дня проверить, нет ли пропущенных недозвонов.

4. Частые проблемы

Проблема Решение
Не загружается сайт Попробуйте резервный адрес ru.tone-crm.ru:8443, Wi-Fi или VPN
Забыл пароль Обратитесь к руководителю
Нет новых лидов Проверьте фильтры в таблице
Не сохраняется карточка Проверьте интернет, перезагрузите страницу
Не открывается документ Проверьте формат и размер файла
